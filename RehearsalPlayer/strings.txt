PLUGIN_REHEARSAL_PLAYER_SPOTIFY_SETUP_TITLE
	EN	Spotify App Credentials

PLUGIN_REHEARSAL_PLAYER_SPOTIFY_SETUP_HELP
	EN	Rehearsal Player uses the official Spotify Web API so teachers can browse and add tracks to shared Spotify playlists from their own accounts. This needs a one-time setup:

PLUGIN_REHEARSAL_PLAYER_SPOTIFY_SETUP_STEP1
	EN	Create a free app at developer.spotify.com/dashboard (any Spotify account can do this).

PLUGIN_REHEARSAL_PLAYER_SPOTIFY_SETUP_STEP2
	EN	Host the included spotify-oauth-bridge.html page somewhere with HTTPS (e.g. GitHub Pages) - see SPOTIFY_SETUP.md in this plugin's repository for step-by-step instructions.

PLUGIN_REHEARSAL_PLAYER_SPOTIFY_SETUP_STEP3
	EN	In the Spotify app's settings, add that page's URL as a Redirect URI, then paste the same URL into "Bridge Page URL" below.

PLUGIN_REHEARSAL_PLAYER_SPOTIFY_SETUP_STEP4
	EN	Copy the app's Client ID and Client Secret into the fields below and save.

PLUGIN_REHEARSAL_PLAYER_SPOTIFY_CLIENT_ID
	EN	Client ID

PLUGIN_REHEARSAL_PLAYER_SPOTIFY_CLIENT_SECRET
	EN	Client Secret

PLUGIN_REHEARSAL_PLAYER_SPOTIFY_BRIDGE_URL
	EN	Bridge Page URL

PLUGIN_REHEARSAL_PLAYER_SPOTIFY_BRIDGE_URL_DESC
	EN	The HTTPS page that bounces a teacher's browser from Spotify back to this Lyrion server. Must exactly match a Redirect URI registered on the Spotify app. See SPOTIFY_SETUP.md.
